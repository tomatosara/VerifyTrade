# Gemini Project Context: Backend

This document provides specific instructions and context for the backend of the VerifyTrade project.

## Technology Stack

-   **Framework:** Express.js
-   **Language:** TypeScript
-   **API Generation:** `tsoa` is used for generating OpenAPI specs and Express routes from controllers.
-   **ORM:** TypeORM
-   **Database:** PostgreSQL
-   **Testing:** Jest

## Project Structure

-   `src/modules`: Contains the business logic, organized by feature. Each module may contain `controller`, `service`, `entity`, and `dto` subdirectories.
-   `src/database`: Contains database-related files, including migrations, seeds, and the TypeORM data source configuration.
-   `src/http`: Contains files related to the HTTP layer, such as `routes.ts` (generated by `tsoa`) and authentication middleware.
-   `tsoa.json`: Configuration file for `tsoa`.
-   `jest.config.ts`: Configuration file for Jest.

## API and Routing

-   The base path for all API routes is `/api/v1`.
-   Controllers are located in `src/modules/**/controller/*.controller.ts`.
-   `tsoa` generates the Express routes in `src/http/routes.ts`. Do not edit this file manually.
-   To regenerate the routes and the OpenAPI specification, run: `pnpm openapi`

## Database Migrations

The project uses TypeORM for database migrations.

-   **To generate a new migration:**
    ```bash
    pnpm db:generate --name=YourMigrationName
    ```
-   **To run migrations:**
    ```bash
    pnpm typeorm:migrate:run
    ```
-   **To revert a migration:**
    ```bash
    pnpm typeorm:migrate:revert
    ```

## Seeding the Database

The project has a seeding mechanism to populate the database with initial data.

-   **To seed the database:**
    ```bash
    pnpm db:seed
    ```

## Testing

-   Tests are written with Jest and are located alongside the source code (e.g., in `__tests__` directories or with `.spec.ts` / `.test.ts` extensions).
-   The Jest configuration (`jest.config.ts`) includes path aliases for easier importing.
-   To run all tests:
    ```bash
    pnpm test
    ```
